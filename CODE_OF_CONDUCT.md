# Code of Conduct

Abi_KGB is committed to a professional, respectful, and technically constructive community.

Participants are expected to:

- discuss ideas and code without personal attacks,
- provide reproducible evidence when challenging technical behavior,
- respect privacy and site-security constraints when sharing HPC diagnostics,
- acknowledge contributions appropriately, and
- avoid harassment, discrimination, threats, or deliberately disruptive conduct.

Maintainers may edit or remove content and restrict participation when behavior materially interferes with a safe and productive project environment. Concerns can be raised privately with the maintainer when public discussion is inappropriate.
