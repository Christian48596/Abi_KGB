# Security policy

Abi_KGB executes local system-inspection commands and can invoke ABINIT/MPI when a live autoparal probe is requested. Inputs should therefore be treated as local trusted research files.

Do not report credentials, tokens, private SSH configuration, scheduler account secrets, or proprietary input files in public issues.

Security-sensitive reports should be sent privately to the repository maintainer through the contact mechanism listed on the GitHub profile until a dedicated security-contact address is established.
